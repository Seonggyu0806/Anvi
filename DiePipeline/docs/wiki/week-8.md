## 1. 정상 die 자동 맞춤

- 증상: 결함 없는 실데이터 die 를 뷰어 영역으로 검사 → 정합 레시피에서도 오검 다수
- 원인: 손으로 그린 정상 die 별 어긋남 제각각(수 ~ 십수 px) → 합친 골든 번짐 → 패턴 윤곽 잔류
- 처리: 다이 에디터 적용 시 정상 die 별 위상 상관 측정 → 상자 정수 px 이동, 남은 소수점은 레시피 정합
- 거부 조건: 응답 0.2 미만 · 이동량 die 한 변의 1/8 초과 · 이미지 경계 초과
- 결과: 같은 영역 오검 수십 개 → 0

## 2. 뷰어 · 레시피 역할 정리

- 원본 이미지 뷰어: 검사 위치(검사 die · 정상 die)
- 다이 블록 에디터 레시피: 검사 방법(정합 · 임계 · 면적 하한)
- 실데이터 뷰어 검사: `die.diff.align` 사용(기본 그래프는 합성 견본용)

## 3. 동기 방식 비교

- 같은 흐름: 뷰어 영역 → 다이 에디터 미리보기
- 동기 레시피: 정상 die 합성 후 검사 die 1회 정합 + 빼기 뒤 Median 3
- 정상 die 개별 어긋남 미보정 → 같은 한계, 우리는 상자 단위 사전 맞춤

## 4. 결함 조각 통계 계산 개선

- 밝기 · 원형도: 조각 경계 상자 안에서만 계산(die 전체 탐색 제거)
- 결과 동일(실데이터 회귀 통과) · 조각이 많을 때 처리 시간 단축

## 5. 옵션 검사 작업공간 정리 결정
