## 1. 블록 편집기 공통화

- 편집 로직(ViewModel)과 화면(View)의 공용 컴포넌트 분리
- 탭별 차이는 설정으로 주입: 노드 명부 · 팔레트 필터 · 컨텍스트 입력 · 시작 그래프

## 2. 노드 캔버스

- Nodify 7.3.0(교수님 구현과 동일) — 포트 드래그 연결 · 확대/이동 · 전체 보기
- 편집 이력(되돌리기/다시) · 계층형 자동 배치 · 검증 오류 노드 강조
- 연결 해제: 더블클릭 · Alt+클릭

## 3. 웨이퍼 레시피 편집기

- 웨이퍼 전용 팔레트 · 견본 레시피 · `*.wafer.json` 열기/저장
- 실행 패널: 입력 사진 → 실행 → 요약 · 웨이퍼 맵 · 결함 목록
- 명령행 레시피 실행과 동일 실행기 — 결과 동일성 시험
- 저장 위치 변경 시 레시피 내부 상대 경로 재계산

## 4. 복합 파라미터 편집

- 목록형 파라미터 4종: 표식 설계 위치 · 표식 템플릿 · 원판 · 수동 존 지정
- 공용 행 목록 편집 컴포넌트 · 경로 파라미터 파일 선택(레시피 기준 상대 경로)
- 컨텍스트 입력 노드 안내
