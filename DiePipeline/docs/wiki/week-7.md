## 1. 블록 편집기 공통화

- 편집 로직(ViewModel)과 화면(View)의 공용 컴포넌트 분리
- 탭별 차이는 설정으로 주입: 노드 명부 · 팔레트 필터 · 컨텍스트 입력 · 시작 그래프

## 2. 노드 캔버스

- Nodify 7.3.0(교수님 구현과 동일) — 포트 드래그 연결 · 확대/이동 · 전체 보기
- 편집 이력(되돌리기/다시) · 계층형 자동 배치 · 검증 오류 노드 강조
- 연결 해제: 더블클릭 · Alt+클릭

## 3. 웨이퍼 레시피 편집기

- 웨이퍼 전용 팔레트 · 견본 레시피 · `*.wafer.json` 열기/저장
- 실행 패널: 입력 사진 → 실행 → 요약 · 웨이퍼 맵 · 결함 목록
- 명령행 레시피 실행과 동일 실행기 — 결과 동일성 시험
- 저장 위치 변경 시 레시피 내부 상대 경로 재계산

## 4. 복합 파라미터 편집

- 목록형 파라미터 4종: 표식 설계 위치 · 표식 템플릿 · 원판 · 수동 존 지정
- 공용 행 목록 편집 컴포넌트 · 경로 파라미터 파일 선택(레시피 기준 상대 경로)
- 컨텍스트 입력 노드 안내

## 5. 작업공간 · 결과 오버레이

- 탭 → 상단 작업공간 바(다이 · 웨이퍼 · 원본 묶음, 교수님 화면 구성)
- 다이 오버레이: 단계별 중간 이미지 위 결함 박스 · 목록 선택 연동
- 웨이퍼 오버레이: 개요 이미지 위 die 테두리(웨이퍼 맵과 같은 상태 색) · 결함 박스

## 6. 원본 이미지 뷰어

- 대용량 원본 표시: 축소본 + 가시 영역 원본 해상도 크롭
- 커서 기준 확대 · 이동 · 화면 맞춤 · 커서 위치 원본 좌표와 픽셀값
- 웨이퍼 결함 → 원본 위치 이동: 결함 표시 · 선택 결함 강조 · 100% 중앙 배치

## 7. 영역 지정과 에디터 연계

- 검사 ROI · 정상 die · 정렬 특징 지정 — 기준 크기 고정 도장(die-to-die 동일 크기)
- 다이 미리보기 입력 전환: 합성 견본 ↔ 원본 ROI · 정상 die
- 정렬 특징 → 웨이퍼 레시피 표식 설계 위치 · 표식 템플릿
- 영역 케이스 파일(`*.case.json`, 교수님 형식) 저장 · 불러오기 · 명령행 `run --case` · 골든 패치 내보내기
- 원본 파생 자료의 레포 내부 저장 차단

## 8. 계측과 결함 보고서

- 두 점 거리 측정(px · µm · Δx · Δy)
- µm/px 환산: raw 사이드카 값 · 수동 입력
- 결함 보고서 CSV · JSON(교수님 형식) — 원본 입력에만 환산 적용

## 9. 실시간 웨이퍼 실행 · die 미리보기

- 진행 알림: 격자 준비 → die 마다 → 완료 · 진행 막대 · 경과 시간
- 웨이퍼 맵 실시간 채색(대기 → 결과)
- die 선택 → 다이 미리보기: 러너와 같은 ROI · 골든 · 원판, 값 변경 시 즉시 재검사
- 정합 견본 레시피 `die.diff.align`(정합 + 빼기 뒤 Median 3)

## 10. 웨이퍼 맵 표시 정리

- 교수님 색 짝: E1 연두/분홍 · E0 청회/주황 + 대기 · 수동 제외(빗금 ×) · 검사 실패
- 칸 틈 · 영역 맞춤 축소 · 범례
- 없는 블록이 든 레시피 열기 → 오류 안내(앱 종료 방지)

## 11. 뷰어 화질 · 영역 찍기 보정

- 축소 표시 보간 · 평균 축소본 백그라운드 교체(병렬 읽기)
- 고정 크기 영역: 끄는 동안 실제 찍힐 상자 미리보기
- raw 설명 파일 누락 안내

## 12. 실데이터 점검 — 노치 · 존 · 정렬 마크

- 노치 걸친 die: 수동 제외 유지(원 판정은 노치 미반영)
- E0 판정: 원 기준(교수님 `CircleZoneRule`) ↔ 이웃 기준(동기) 차이 확인
- 정렬 마크 비교: 동기 · 교수님 · 우리
- 부분 촬영 레시피에 교수님 방식 정렬 추가 · 회귀 경우 추가
- 교수님 실데이터 골든마스터(주입 결함)와 검출 결과 전부 일치
- 결함 심기 시험 폐기
