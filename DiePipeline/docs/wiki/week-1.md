## 한 일

### 1. 학습 자료 주제별 정리

Lesson01~16을 주제 4개로 묶고, 주제마다 코드와 설명 문서를 짝으로 두었다.

| 주제 | 내용 |
|---|---|
| opencv | 이미지 처리와 검사 파이프라인 |
| unittest | 테스트 작성법 |
| wpf | 화면(UI) |
| step | 진행 단계 기록 |

opencv 기초는 검사 순서에 맞춰 4단계로 나눴다.
이미지 다루기 → 전처리(이진화·블러) → 결함 검출(윤곽·면적·합불 판정) → 검사 영역 관리(ROI·레시피 파일)

### 2. 비어 있는 부분 확인

각 Lesson은 개념을 이해하는 데서 끝났다.
처리 단계를 연결해 실제로 동작하는 검사 프로그램은 없었다. 2주차부터 이것을 만든다.

### 3. 프로젝트에 쓸 학습 자료

| 자료 | 내용 | 쓰는 곳 |
|---|---|---|
| Lesson15 | 파이프라인 엔진 + JSON 레시피 | 프로그램의 뼈대 |
| Lesson16 | 웨이퍼 단위 검사 | 웨이퍼 층 |
| Lesson09 | 테스트 방법 | 검증 |
| Lesson08 | WPF 화면 구조(MVVM) | 화면 |

- **파이프라인 엔진**: 처리 단계(노드)를 순서대로 실행하는 실행기. 단계 사이의 데이터는 이름을 붙여 공유 저장소에 넣고 꺼낸다
- **레시피**: 실행할 단계·순서·파라미터를 적은 JSON 파일. 코드를 바꾸지 않고 검사 조건을 바꿀 수 있다
- **레시피 검증**: 실행 전에 단계 이름·연결·값 범위가 맞는지 검사한다
- **테스트 원칙**: 실수 계산 결과는 허용오차로 비교한다. 마지막 자리가 실행마다 달라질 수 있기 때문이다
