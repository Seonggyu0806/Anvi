# 2주차 — die 검사 파이프라인 첫 완성

`2026-09-04 ~ 09-11`

## 요약

1. die 한 장을 검사하는 파이프라인(7단계)을 처음부터 끝까지 동작하게 만들었다
2. 실데이터에서 오검 0개, 지름 4px 결함까지 검출했다
3. 동기와 각자 구현한 결과를 비교했다 → 다음 주에 공통 기준으로 다시 만들기로 했다

## 한 일

### 1. die 검사 파이프라인

- die: 웨이퍼 위에 같은 모양으로 반복해 만든 칩 하나
- 검사 방식: 이웃 die 여러 장을 합쳐 정상 기준 이미지(골든)를 만들고, 검사할 die와의 차이를 결함 후보로 본다

| 단계 | 하는 일 |
|---|---|
| Combine | 이웃 die를 합쳐 골든 생성 |
| Normalize | 두 이미지의 밝기 조건을 맞춤 |
| Align | 위치 어긋남 보정 |
| Difference | 골든과의 차이 계산 |
| Filter | 잡음 제거 |
| Binarize | 결함 / 정상 판정 |
| Label | 결함 영역을 개수·면적 목록으로 정리 |

처리 순서와 값은 JSON 레시피 파일이 정한다. 코드를 바꾸지 않고 검사 조건을 바꿀 수 있다.

### 2. 3층 구조

| 층 | 역할 |
|---|---|
| Core | 실행 엔진과 레시피. 이미지 라이브러리에 의존하지 않는다 |
| OpenCv | 알고리즘 구현 |
| App | 명령행 실행 |

### 3. 실데이터 첫 검사

- 정상 영역 오검 0개, 인공 결함 지름 4px까지 검출
- 문제: 반복 무늬에서 Align이 위치를 잘못 맞춰 정상 영역에서 결함 11개가 나왔다
- 해결: 정합 결과의 신뢰도를 검사해, 믿을 수 없으면 검사를 멈추게 했다

### 4. 성능

1024×1024 한 장 90 ms → 44 ms. 결과가 바뀌지 않은 것을 함께 확인했다.
