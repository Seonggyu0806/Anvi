# 6주차 — 웨이퍼 입력 보완과 웨이퍼 레시피

`2026-10-02 ~ 10-09`

## 요약

1. raw 원본 직접 입력
2. die 수동 존 지정
3. 결함 원본 보기
4. 화면 입력 확장
5. 웨이퍼 레시피
6. 실데이터 회귀 시험

## 1. raw 원본 직접 입력

- 사이드카(`<원본>.raw.json` — 폭 · 높이 · 픽셀당 바이트 · 행 순서) 기반 raw 입력. 키 이름은 교수님 구현과 동일
- 파일 크기 검증(폭 × 높이 × 픽셀당 바이트) · BMP 입력과 결과 동일

## 2. die 수동 존 지정

- 원판 판정 오류(노치) 보정 — die 단위 존 덮어쓰기 `열,행=E1|E0|off`(교수님 문서의 수동 오버라이드 목록)
- `off`: 검사 · 이웃(골든) 제외. 격자 밖 · 중복 지정은 실행 전 거부

## 3. 결함 원본 보기

- 결함 선택 시 원본 해상도 주변 창 표시 — 결함 긴 변의 4배, 128~1024 px

## 4. 화면 입력 확장

- 웨이퍼 탭: 정렬 표식(템플릿 · 설계 위치 · 탐색 범위) · 수동 존 지정
- die 탭 미리보기: 원판 마스크 입력 레시피 지원
- 글자 입력 규칙 단일화(명령행 · 화면 공용)

## 5. 웨이퍼 레시피

- 웨이퍼 검사 설정의 단일 파일화(`*.wafer.json`) — 교수님 통합 블록 레시피와 동일 구조
- 블록 5종: 표식 탐색 → 자세 계산 → die 전체 검사 → 웨이퍼 좌표 변환 → 결과 샘플링
- 실행기의 레시피 분할 실행(표식별 · die별 반복)
- 명령행 옵션 · 레시피 파일 두 입구, 단일 검사 흐름 — 결과 동일성 시험

## 6. 실데이터 회귀 시험

- 확인된 실데이터 결과(정렬 · die 수 · 결함 목록)의 기준 파일 고정 및 허용오차 비교
- 대상: 원판 · 부분 촬영 2건. 자료는 레포 외부 보관, 원본 없는 환경에서는 생략
