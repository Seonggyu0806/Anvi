# 4주차 — 웨이퍼 층: 웨이퍼 한 장을 처음부터 끝까지 검사

`2026-09-18 ~ 09-25`

## 요약

1. die 격자를 만들고 가장자리 die(E0)를 따로 구분했다
2. 이웃 선택 · 러너 · 결함 모으기 · 좌표 변환을 붙여 웨이퍼 한 장을 처음부터 끝까지 검사하게 만들었다
3. 레시피가 요구하는 골든 장수가 모자라면 검사를 멈추게 했다
4. 정렬 표식으로 웨이퍼가 놓인 각도와 위치를 계산한다
5. 시험용 웨이퍼 생성과 결함 샘플링을 붙였다

## 한 일

### 1. 웨이퍼 층이 필요한 이유와 설계

- 골든을 만들려면 이웃 die가 필요하고, 누가 이웃인지는 웨이퍼 격자만 안다
- die 개수는 웨이퍼마다 실행할 때 정해진다. 그래서 die 반복은 레시피(엔진) 밖의 웨이퍼 층이 맡고, 엔진은 die 하나를 레시피대로 처리한다
- Lesson16과 교수님 구현도 같은 구조다

### 2. 격자와 존

- 격자: 원점 · 피치(die 간격) · 열×행으로 die마다 위치를 계산한다
- E1: 이웃이 모두 있는 die → 이웃과 비교하는 die-to-die 검사
- E0: 웨이퍼 원판 가장자리에 걸친 die → 이웃으로 골든을 만들 수 없어 단일 임계값(아주 어두운 영역)으로 검사한다. 밝은 결함은 잡지 못한다
- E0는 이미지 테두리가 아니라 웨이퍼 원판의 가장자리다. 지금 실데이터는 웨이퍼 안쪽을 부분 촬영한 것이라 전부 E1이다
- 가장자리 몇 겹을 E0로 볼지 정할 수 있다. 원판의 중심 · 반지름으로 판정하는 것은 검증할 데이터가 없어 미뤘다
- 잘못된 값(열 · 행 0, 피치 0, die가 피치보다 큼, 확대율 0)은 거부한다

### 3. 웨이퍼 한 장 검사 흐름

이미지 → 격자 → die마다 이웃을 골라 검사 → 결함 모으기 → 웨이퍼 좌표 변환 → 지도 출력 (명령행 `wafer`)

| 구성 | 하는 일 |
|---|---|
| 이웃 선택 | E1 die에서만 골든용 이웃을 고른다 |
| 러너 | die 위치만 계산해 검사 함수에 넘기고 결과를 모은다. 이미지를 직접 다루지 않아 이미지 없이 테스트할 수 있다 |
| 결함 모으기 | die별 결과 → 웨이퍼 전체 목록 |
| 좌표 변환 | die 안 좌표 → 웨이퍼 절대 좌표. 변환은 한 곳에서만 한다 |

- 이미지 밖으로 걸친 die: 검사 영역은 잘라 내고, 골든은 크기를 맞추려고 안쪽으로 밀어 넣는다
- 종료 코드 3종: 결함 없음 / 결함 있음 / 검사 실패 die 있음. 실패가 "결함 0개"로 보이면 안 되므로 따로 구분한다

### 4. 골든 장수 검사

- 문제: 시험 웨이퍼에 결함 3개를 심었는데 9개가 나왔다. 레시피(Median)는 골든 3장을 전제하는데 이웃이 1~2장만 들어가, 이웃의 결함이 골든에 섞였다
- 해결: 레시피의 합치는 방법에서 필요한 장수를 읽어 내고, 모자라면 검사를 멈춘다

### 5. 정렬

- 웨이퍼는 장비에 매번 조금씩 다르게 놓인다. 1° 기울면 300px 떨어진 곳에서 5px 밀린다
- 표식 2개 이상을 찾아 회전과 이동을 계산한다. 표식은 서로 멀리 있고 모양이 비대칭이어야 한다
- 점수가 가장 높은 자리가 틀린 자리일 수 있다(오답 0.98 · 정답 0.93) → 두 표식 사이 거리가 변하지 않았는지 검사한다
- 소수점 단위로 위치를 잡아 각도 오차를 4배 줄였다
- 정렬 결과를 믿을 수 없으면 검사를 시작하지 않는다. 기울기가 크면 멈춘다(die를 펴서 읽는 기능이 아직 없다)

### 6. 시험용 웨이퍼와 샘플링

- 시험용 웨이퍼: 실데이터는 레포에 넣지 않으므로, 결함 위치(정답)를 아는 웨이퍼 이미지를 코드로 만든다
- 샘플링: 검사는 전부 하고 보여 줄 결과만 추린다(큰 순서 · 면적 범위 · 무작위). 같은 입력이면 항상 같은 결과가 나온다
- 덜어낸 개수를 함께 표시하고, 판정(종료 코드)은 추리기 전 결과로 한다
